# 📣 proximamente-api

Una API desarrollada en **Node.js**, **Express** y **TypeScript** que permite a los usuarios registrarse para recibir novedades sobre el lanzamiento de mi portfolio y futuros proyectos. Usa **MySQL** como base de datos y se integra con **n8n** para el envío automatizado de correos electrónicos.

## 🚀 Funcionalidad

- Registro de usuarios con su correo electrónico.
- Validación de datos.
- Notificación automática mediante **n8n**.
- API REST con endpoints seguros y estructurados.
- Base de datos relacional con MySQL.

## 📦 Tecnologías usadas

- Node.js
- Express
- TypeScript
- MySQL
- n8n (automatización de flujos de trabajo)
- Dotenv (variables de entorno)
- Axios (para consumir n8n)
- Cors, Helmet, Morgan (middlewares comunes de seguridad y logs)
